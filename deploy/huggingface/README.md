# Prompt Laboratory

Prompt Laboratory is a cross-industry, Git-native quality engineering platform for prompts. It helps AI teams create, version, test, evaluate, compare, approve, and safely release prompts.

## Public demonstration

This Space is an isolated, mock-only product demonstration:

- Streamlit is exposed on port 7860.
- FastAPI runs inside the container on loopback only.
- Visitors receive isolated anonymous demo sessions.
- Data is temporary and may reset when the Space restarts.
- Only the deterministic mock provider is available.
- Live provider credentials and production traffic are intentionally disabled.

Do not enter personal, confidential, regulated, or production information.

Source code and engineering history: https://github.com/Anne07-Ai/prompt-laboratory
